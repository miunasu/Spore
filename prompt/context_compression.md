# 上下文压缩任务

你需要压缩以下对话历史，保留与当前话题最相关的核心信息。

## 压缩原则

1. **识别当前话题**：分析最新几轮对话，明确用户当前正在处理什么任务或讨论什么话题

2. **提取相关上下文**：
   - 与当前话题直接相关的讨论内容
   - 为理解当前任务所必需的背景信息
   - 已经完成的关键步骤和决策
   - 正在进行中的工作和待办事项

3. **保留精确信息**（不可压缩）：
   - 具体的命令、代码片段、配置项
   - 文件路径、函数名、变量名
   - 数字、日期、版本号
   - API端点、URL、错误信息
   - 用户明确提出的需求和约束条件

4. **压缩非关键内容**：
   - 与当前话题无关的历史讨论可以省略
   - 重复的说明可以合并
   - 过程性的试错内容可以简化为结论

5. **保持连贯性**：
   - 确保压缩后的内容逻辑清晰
   - 保留必要的上下文关联
   - 突出当前任务的进展状态

## 输出要求

- 使用自然语言输出，结构清晰
- 直接给出压缩内容，不要包含任何元标记（如 "总结如下："、"压缩结果："）
- 不要输出代码块、JSON格式或函数调用标记
- 使用中文输出
- 按时间顺序或逻辑顺序组织内容
- 对于精确信息（命令、路径、代码等），必须完整保留原文

## 示例格式

用户正在[当前任务描述]。

[背景信息]：...

已完成的工作：
1. ...
2. ...

当前进展：...

待处理事项：...

关键技术细节：
- 配置项：`KEY=value`
- 文件路径：`path/to/file`
- 相关命令：`command --flag`
